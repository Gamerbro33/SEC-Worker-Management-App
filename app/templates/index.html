Instructions

Sign in or Sign Up

  1. Create a Account(If you are a worker make sure Worker Type is Worker. If you are a project manager set worker type as Project Manager)
  2. Sign in with your account

If you are a worker

  1. Choose a jobsite on the side bar
      2. Two things to keep note of:
    1. If your are using this app on your mobile phone the press the 3 line button on the top right
    2. You will see jobsites if you are assigned to them by the project managers
  2. Press the Go to Jobsite button you will see the jobsite location on the map and your location

If you are a project Manager

  1. Add a jobsite(Enter the name description latitude and longitude(OR double click the map to place a marker), and enter how big you want the radius)
  2. You can view it, remove or edit the jobsite however you want
  3. Assign a worker
    • Now Workers can see the assign jobsite on the map and project manager can see them by pressing the view button on jobsite card
    • on the time card page when they are in or out of the jobsite radius they will be clock-in/clock-out

The reason we made this app is to help Starr electric company have a way to manage workers and allow them to clock into jobsite by just entering for convience and accuracy.
